# جولة المراجعة — جرّب قواعد النظام بنفسك

هذه الجولة تعمل على بيئة محلية كاملة على جهازك (قاعدة بيانات + Supabase + التطبيق) ببيانات تجريبية:
جامعة واحدة، 80 طالباً، 3 أسابيع من سجل المسح. لا تلمس أي خادم حقيقي.

## التشغيل

```bash
npm run review        # أول مرة: عدة دقائق. يطبع الرابط وجدول الحسابات
npm run tour          # اختياري: يولّد لقطات الشاشة في مجلد screenshots/
npm run review:stop   # إيقاف البيئة (البيانات تبقى للمرة القادمة)
```

افتح الرابط الذي يطبعه الأمر (غالباً `http://localhost:8787`، لأن المنفذ 8080 يستخدمه Steam على جهازك).
للتبديل بين الحسابات بسهولة: افتح المدير في نافذة عادية والمشرف في نافذة خاصة (InPrivate/Incognito).

| الدور | رمز الدخول | كلمة المرور |
|---|---|---|
| مدير النظام | `ADMIN` | `Admin@12345` |
| مشرف عام (للجامعة) | `GS-01` | `Demo@12345` |
| مشرف | `SUP-01` | `Demo@12345` |
| طالب مُرقّى لمشرف | `SHB-0003` | `Demo@12345` |
| طالب | `SHB-0001` | `Demo@12345` |
| طالب بأول دخول | `SHB-0075` | `SHB-0075` (يطلب تغيير كلمة المرور ثم رفع الصورة) |

> المتصفح سيطلب إذن الموقع في شاشة المسح — اسمح به. إن لم يتوفر موقع على جهازك، أوقف
> «إلزام المشرف بتفعيل الموقع» من الإعدادات أثناء التجربة.

## التحضير (مرة واحدة — دقيقتان)

1. ادخل كـ `ADMIN`.
2. **الإعدادات** ← اجعل «فترة منع المسح المتكرر (بالدقائق)» = `0` ← حفظ.
   (القيمة الافتراضية 5 دقائق تمنع المسح المزدوج بالخطأ؛ نصفّرها فقط لنجرب بسرعة.)
3. **الطلاب** ← افتح `SHB-0001` ← «تعديل» ← فعّل كل أيام الدوام السبعة ← حفظ.
   سجّل الرقم الظاهر في «رصيد هذا الأسبوع» (مثلاً `3 من 4`).

| 8 | ادخل كطالب `SHB-0001` (نافذة ثالثة أو بعد الخروج) | الرئيسية تُظهر الرصيد الجديد، و«رحلاتي» تُظهر ذهاب وعودة اليوم |
| 9 | كمدير: **سجل المسح** ← «إلغاء المسح» على مسح الذهاب لـ `SHB-0001` مع سبب | يُلغى الذهاب **والعودة** معاً وترجع الرحلة للرصيد |
| 10 | كمدير: **استيراد الطلاب** ← الملف `supabase/seed/demo-import.xlsx` ← تحليل ← معاينة | 60 صف: 53 جديد، 3 مكرر، 4 مرفوض مع الأسباب بالعربي (لا تضغط تأكيد إن لم ترد إضافتهم) |
| 11 | كمدير: **الطلاب** ← «طباعة البطاقات» | صفحة A4 بعشر بطاقات؛ من نافذة الطباعة اختر «حفظ كـ PDF» |
| 12 | ادخل كـ `SHB-0075` / `SHB-0075` | تغيير كلمة مرور إجباري ← خروج تلقائي ← دخول ← رفع صورة إجباري |

## أعد الإعدادات بعد التجربة

أرجع «فترة منع المسح» إلى `5` وأوقف «السماح بتجاوز أيام الدوام» إن كنت تريد الوضع الافتراضي
(هذا يخص البيئة المحلية فقط).
